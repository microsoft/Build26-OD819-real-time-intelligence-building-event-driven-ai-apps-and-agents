# [Microsoft Build 2026](https://build.microsoft.com)

## 🔥 OD819: RTI at Build: Real-Time Intelligence for Developers - Building Event-driven Apps and Agents

### Session Description

Fast-paced, On-Demand session with live demos showing how to build real-time, event-driven applications and intelligent agents using Microsoft Fabric Real-Time Intelligence. The session covers end-to-end solutions from ingestion to action, with a focus on Eventstreams, Eventhouses, Real-Time Dashboards, Activator, Operations Agent, new Model Context Protocol servers, and more.

### 🚀 Getting started

To get started with this session:
- Clone this repository
- Set up your development environment
- Pick a scenario from the Resources section and build an end-to-end flow from Eventstreams ingestion to automated action.

### 🧠 Learning Outcomes

By the end of this session, you will be able to:

- Build end-to-end real-time solutions in Microsoft Fabric Real-Time Intelligence, from ingestion to automated action.
- Design event-driven architectures using Eventstreams, Business Events, Activator, Eventhouses, and Real-Time Dashboards for low-latency analytics.
- Implement intelligent operational workflows with Activator, Anomaly Detector, Operations Agent, and Model Context Protocol integrations.
